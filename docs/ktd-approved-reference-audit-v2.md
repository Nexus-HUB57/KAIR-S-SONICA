# Auditoria das referências aprovadas — FIRE IN THE FLOOD v2

Fonte direta: [pasta `assets/video/aprovados` no GitHub](https://github.com/Nexus-HUB57/KAIR-S-SONICA/tree/main/assets/video/aprovados).

A pasta aprovada contém vídeos verticais de 720×1280, 24 fps, com áudio AAC, em planos contínuos de 8–10 segundos. Os exemplos canônicos incluem `fire-in-the-flood-ktd-approved-dynamic-8s.mp4`, `six-names-ktd-clip-table-candles-10s-with-audio (1).mp4` e `unleash-the-dragon-realgclip-01-dressing-room-10s-with-audio.mp4`.

O padrão obrigatório para a nova versão é vídeo vivo, não still com zoom. Em cada plano, KTD deve agir fisicamente, a câmera deve viajar de modo contínuo e o ambiente deve reagir com elementos temporais visíveis como água, chuva, vapor, fumaça, fogo, tecido, cabos, luzes ou passos. O plano aprovado de `Fire in the Flood` usa caminhada deliberada, dolly-back frontal, corredor industrial, porta metálica, luz de recorte e transição orgânica para rua molhada. O plano aprovado de `Six Names` usa uma ação concreta — acender uma vela — com mudança de escala médio para close, fumaça em movimento, alteração de luz e microexpressões.

O videoclipe de 2min48s será reconstruído como 21 planos contínuos de aproximadamente 8 segundos, com começo, desenvolvimento e conclusão de microação em cada plano. Os PNGs de KTD serão apenas referências de identidade, nunca a imagem final do vídeo. Qualquer trecho que possa ser descrito como “foto animada” deverá ser rejeitado e regenerado.

## Critérios de aceite

| Critério | Obrigatório |
|---|---|
| Ação de KTD | Caminhar, tocar, abrir, atravessar, carregar, performar, respirar ou reagir; nunca apenas posar |
| Movimento de câmera | Dolly-back, travelling, arco, handheld sutil, push-in físico ou acompanhamento contínuo |
| Reação do cenário | Água, chuva, vapor, fumaça, fogo, luz, cabos, tecido, portas e reflexos com comportamento temporal |
| Continuidade | Rosto, heterocromia, barba, anatomia, tatuagens, roupa e direção espacial preservados |
| Narrativa | Cada plano contém micro-história; os 21 planos formam o arco janela → enchente → resistência → reconstrução |
| Formato de master | 16:9 para o videoclipe completo, com planos gerados originalmente como vídeo contínuo |
